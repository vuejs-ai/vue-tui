# Records map

Find the code or decision you are about to touch, then open the exact record or heading that covers it.

The Runtime public API review has no remaining Open judgment. The application-facing Runtime API and ownership model are selected and implemented. Official Vite and testing packages now use narrow privileged Runtime-internal bridges; the former public-looking `/devtools` and `/testing` entries are absent. Future additions still require a concrete application need and a separate public-contract decision.
