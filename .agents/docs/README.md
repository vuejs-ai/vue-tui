# Records map

Find the code or decision you are about to touch, then open the narrowest matching record below. Current truth lives in these topic records, code, and executable checks; completed implementation plans and audit handovers stay in Git history.

The Runtime public API review has no remaining Open judgment. The application-facing Runtime API and ownership model are selected and implemented. Official Vite and testing packages use narrow version-coupled Runtime-internal bridges; application-facing packages use only supported public entries.
